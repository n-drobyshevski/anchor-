# Файл настроек Anchor для заметок (8e). Скопируй его в хранилище как
# Anchor/settings.md. Anchor его только читает и никогда не пишет.
#
# Каждая заметка вне папки Anchor/ получает один класс:
#   personal  — о тебе: жизнь, здоровье, отношения, планы, чувства;
#   knowledge — общие знания, верные для любого читателя (CCRU, GCP IAM…);
#   never     — Anchor её не видит, что бы ни было написано в заметке;
#   без класса — Anchor её не видит (так по умолчанию).
#
# Класс задаёт свойство заметки (anchor: personal / anchor: knowledge /
# anchor: never) или правило папки ниже. Правило действует на папку и
# на всё, что в ней. Если они расходятся, побеждает более строгий
# класс: never > personal > knowledge. Заметка «knowledge» в личной
# папке будет личной, и /vault посчитает это как конфликт.
#
# Пути — от корня хранилища, без / в начале и в конце, без папок,
# начинающихся с точки. Life покрывает Life/Diary, но не Lifestyle.
# Правила never_folders действуют без учёта регистра.
#
# Если в этом файле ошибка — неверный YAML, лишний или опечатанный ключ
# (например never_folder), не список, плохой путь или нет строки
# anchor: settings, — Anchor не читает ни одной заметки, пока файл не
# исправят. /vault скажет об этом. Пустой список пиши как [].
anchor: settings
knowledge_folders: [Library, Research/CCRU]
personal_folders: [Life, People]
never_folders: [Life/Diary]
